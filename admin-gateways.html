GhostsPay

Gateway alternativo para balanceamento e backup da operacao.

Sunize

Gateway PIX com autenticacao x-api-key e x-api-secret no backend.

Paradise

Gateway PIX Paradise com webhook nativo e tracking completo.

PinguPag

Gateway PIX PinguPag com webhook nativo e tracking completo.

LumeaPag

Gateway PIX LumeaPag com webhook nativo e tracking completo.

AtlasPags

Gateway PIX AtlasPags com webhook nativo e tracking completo.

ClownPay

Gateway PIX ClownPay com webhook nativo e tracking completo.

Com a ClownPay como gateway principal, o front usa a chave principal e os upsells usam esta subconta. Sem esta chave, todos usam a conta principal.

AtomoPay

Gateway PIX AtomoPay com oferta/produto base e hashes separados para os upsells.

Bravo Pay

Gateway PIX Bravo Pay com idempotencia, UTMs e webhook HMAC.

GhostsPay, Sunize e Paradise seguem a configuracao atual. AtomoPay aceita token de webhook via query string quando configurado. ClownPay confirma os webhooks consultando a API. Bravo Pay usa assinatura HMAC no header X-Bravopay-Signature.
